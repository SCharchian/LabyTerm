# Bundled fonts

- `AdwaitaMono-Regular.ttf`: Adwaita Mono 51.0 (from the `adwaita-fonts` package), unmodified.
  Copyright (c) 2016 The Inter Project Authors; (c) 2015-2025 Renzhi Li (Belleve Invis); (c) 2025 Jamie Gravendeel,
  Florian Muellner. Licensed under the SIL Open Font License 1.1, see `OFL-AdwaitaMono.txt`.

It is the default text font (text glyphs are rasterized from it; all block, box and mosaic glyphs are synthesized).
Other installed monospace fonts are offered in the font lab and used as per-glyph fallbacks.
- `VT323-Regular.ttf`: VT323 by Peter Hull, a recreation of the DEC VT220 terminal font. SIL OFL 1.1, see `OFL-VT323.txt`.
  Unmodified.
